# 賞味期限リマインダー

食品在庫の賞味期限を管理し、期限が近づいたらメールで通知する社内向けWebアプリ。

## 使い方

- アプリ本体: `index.html`（GitHub Pagesで公開して利用）
- サーバー側: `gas-spreadsheet-sync.gs`（Google Apps Scriptに貼り付けて使用）

## 主な機能

- 商品の登録・編集・並び替え・フィルター
- 売上／廃棄の記録と履歴管理
- 仕入れ先カテゴリ管理（カテゴリごとの通知ON/OFF）
- PDF（お届け情報）からのOCR一括登録
- Googleスプレッドシートによるチームデータ共有
- 毎朝の自動リマインドメール送信

## 開発・運用メモ

詳細は `CLAUDE.md` を参照。アプリの変更はGitHubへのプッシュで反映され、GASの変更は別途エディタへの貼り付け＋再デプロイが必要。
